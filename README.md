# Cases and Materials on Family Law for the South Dakota Lawyer — 2010

Historical website for Roger M. Baron's Seventh Edition, published July 2010.

## Render
- Runtime: Python
- Build command: `python3 -m py_compile server.py`
- Start command: `python3 server.py`
- The server binds to `0.0.0.0` and uses Render's `PORT` environment variable.
- The SQLite database is a read-only, bundled historical search database; it is not modified at runtime.

## Historical preservation
The website preserves the 2010 edition and does not incorporate post-2010 legal developments into the book.
